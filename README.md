# BusID - Digital College Bus Pass System

BusID is a web-based digital bus pass management system developed for college students and administrators.

## Features

- Student Registration
- Secure Authentication
- Admin Approval Workflow
- Digital Bus Pass Generation
- Pass Status Tracking (Active, Pending, Expired)
- Student Profile Management

## Technologies Used

- React
- Supabase
- PostgreSQL
- Vercel
